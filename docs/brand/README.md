# Bastion Rush Brand Asset

`app-icon-original-1536.png` was generated with OpenAI's built-in image generation tool and then flattened/resized to `AppIcon.png` for the iOS asset catalog.

`battlefield-source.png` was generated with the same built-in tool. An optimized JPEG is shipped as the SpriteKit battlefield backdrop.

## Final generation prompt

```text
Use case: logo-brand
Asset type: iOS App Store icon and in-game brand mark for a portrait squad tactics game
Primary request: Create an original premium app icon for a game titled internally “Bastion Rush”; do not include any words or letters in the image.
Input images: Image 1 and Image 2 are style/composition references only; do not copy their characters, logos, UI, buildings, or layout.
Subject: a bold cobalt-blue toy soldier commander shield, with a small warm-gold chevron/crown motif and a simplified coral-red enemy fortress silhouette behind it
Style/medium: polished low-poly 3D mobile game art, chunky readable forms, slightly tactile painted miniature materials, distinctive rather than generic AI game art
Composition/framing: centered emblem, strong silhouette, fills the square safely, no border, readable at tiny icon size
Lighting/mood: dramatic soft studio lighting, energetic and heroic
Color palette: deep navy background, cobalt blue, warm gold, restrained coral red, ivory highlights
Constraints: square app icon; no text; no letters; no numbers; no UI; no watermark; no copied branding; no photorealism; no guns pointed at viewer; no gore
Avoid: excessive detail, clutter, gradients that wash out, generic medieval shield, recognizable franchise aesthetics
```

## Battlefield generation prompt

```text
Use case: stylized-concept
Asset type: seamless-feeling portrait battlefield background texture for an iOS SpriteKit game
Primary request: Create an original top-down low-poly battlefield environment for Bastion Rush, designed to sit behind bright game characters and UI.
Scene/backdrop: a long vertical dark teal military training road running from bottom to top, subtle segmented paving, shallow worn tire tracks, narrow grassy embankments and occasional small angular rocks/sandbags along the far edges only
Subject: environment only; the central 70 percent must stay open and low-contrast for moving gameplay
Style/medium: polished low-poly 3D mobile game art, tactile painted miniature materials, clean premium geometry, coherent with cobalt-blue, gold, and coral-red characters
Composition/framing: strict top-down portrait composition; centered vertical lane; no horizon; evenly usable from top to bottom; important details confined to outer edges
Lighting/mood: soft directional daylight with restrained ambient shadows, readable but not busy
Color palette: deep navy, muted teal asphalt, desaturated green edges, small warm sand accents
Materials/textures: subtle rough paving, low-poly grass, soft bevels
Constraints: no characters; no soldiers; no vehicles; no weapons; no mines; no buildings; no UI; no text; no letters; no numbers; no logos; no watermark; no bright objects in the central lane; game elements must remain easy to read over it
Avoid: photorealism, dramatic perspective, horizon, clutter, high-frequency detail, excessive bloom, recognizable franchise aesthetics
```
